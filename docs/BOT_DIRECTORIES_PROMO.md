## 📢 Готовий шаблон для статті на DOU.ua / dev.ua («Пет-проєкт»)

**Тема:** Як я автоматизував пошук та відгуки на Freelancehunt за допомогою AI та Telegram Mini App

**План статті:**
1. **Проблема:** Фрілансери витрачають 2–3 години щодня просто оновлюючи сторінку та пишучи однотипні відгуки. Хто перший відповів — той забрав замовлення.
2. **Рішення:** Створення `@HUNTua_bot`, який перевіряє API кожні 3 хвилини, аналізує вимоги клієнта та за допомогою AI формує влучний відгук з уточнюючими питаннями.
3. **Стек проекту:** Python (aiohttp, python-telegram-bot), SQLite WAL, Ollama/OpenAI, Telegram Mini App.
4. **Результати:** Швидкість відгуку скоротилася з 20 хвилин до 10 секунд.
5. **Посилання для спільноти:** 7 днів безкоштовного доступу для всіх читачів DOU/dev.ua.
